# Lab 1 starter workspace

Use this directory with the complete **Lab 1: Terminal and Vim** assignment in
Canvas. Start the lab from this directory:

```bash
cd labs/lab-01
```

The supplied files have distinct roles:

- Run `practice/probe.sh` without editing it.
- Repair `broken_greeting.sh`; it intentionally starts with two small defects.
- Edit `server.conf` in Vim as directed by the assignment.
- Complete the four marked student slots in `sysreport.sh`, then add one
  independent field.
- Keep your observations and checks in `lab_record.yml`.

Before each probe, make a serious prediction and optionally write it in your
own notes. Prediction answers are not submitted or graded. Comparing them with
the observed result helps prepare you for quizzes, the final project, and exams.

Do not place credentials, private keys, or student identification numbers in
this directory. The assignment document is authoritative when this short file
and Canvas differ.
