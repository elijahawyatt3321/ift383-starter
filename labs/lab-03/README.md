# Lab 3 starter workspace

Use this directory with the complete **Lab 3: Text and Data Pipelines**
assignment in Canvas. Start here:

```bash
cd labs/lab-03
```

- Treat `access.log`, the worked-example files, `guided_tools/`, and
  `pipeline_probes.sh` as read-only fixtures.
- Repair and extend `toptalkers.sh`.
- Complete the three core slots and the separate transfer slot in
  `scan_report.sh`.
- Complete the three guided value slots in `json_summary.sh`; use the supplied
  `json_encode.py` serializer without editing it.
- Record observations, tool roles, and checks in `lab_record.yml`.

Before each probe, make a serious prediction and optionally write it in your
own notes. Prediction answers are not submitted or graded. Comparing them with
the observed result helps prepare you for quizzes, the final project, and exams.

`findings.txt` and `summary.json` are intentionally absent until you generate
them. Use only the provided bounded logs; they contain documentation-only
example addresses and no real user data.
