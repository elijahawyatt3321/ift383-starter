# Lab 4 starter workspace

Use this directory with the complete **Lab 4: Safe Bash Automation** assignment
in Canvas. Start here:

```bash
cd labs/lab-04
```

Run `bash tests/reset_fixture.sh` before each apply-mode experiment. The
untouched starter has two intentional failures at one marked action boundary;
`bash tests/run.sh` names them without operating outside this directory.

Use `SCHEDULER_GUIDE.md` and complete exactly one template in `schedule/`.
`run.log`, `last_run.json`, `tests/test_json_report.sh`, and
`scheduler_status.txt` are intentionally absent until your work creates them.
The assignment teaches the JSON boundary and the shell-test pattern before you
write either file. Never aim this lab at a personal, system, or real log
directory, and never use `sudo` for this lab.

Before each probe, make a serious prediction and optionally write it in your
own notes. Prediction answers are not submitted or graded. Comparing them with
the observed result helps prepare you for quizzes, the final project, and exams.
