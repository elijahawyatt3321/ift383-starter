# Lab 2 starter workspace

Use this directory with the complete **Lab 2: Private Git Workflow** assignment
in Canvas. Run the branch setup once from the repository root:

```bash
bash labs/lab-02/setup_branches.sh
```

The script creates two local branches from the same commit and returns you to
`main`. It does not use the network, push a branch, or change a remote. You will
inspect and merge those branches as directed by the assignment.

Keep observations, merge decisions, and quick checks in `lab_record.yml`.
Before each probe, make a serious prediction and optionally write it in your
own notes. Prediction answers are not submitted or graded. Comparing them with
the observed result helps prepare you for quizzes, the final project, and exams.
`git_evidence.txt` is intentionally absent until you create it. The complete
assignment remains authoritative.
